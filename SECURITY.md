# Security policy

This repository is a **deliberately vulnerable security lab** maintained as its author's
own test system. The vulnerabilities in `app/` are intentional and documented in the
findings report.

- Do not report the intentional lab findings as security issues — they are the point.
- Do not deploy this target or expose it to a network.
- Do not use the attack tooling or the phishing templates against any system or person
  you are not explicitly authorized to test. Unauthorized testing is illegal.

If you find an *unintended* issue (for example something that affects users who merely
clone the repo), open an issue describing it.
